# Function 1: `get_output_path(filename)`

```python
def get_output_path(filename):
```

## Responsibility

Creates a unique filename so existing files are never overwritten.

### Workflow

1. Create output directory if missing.
2. Extract filename.
3. Extract stem and extension.
4. Build output path.
5. Check whether file exists.
6. If exists:
   - append `_1`
   - append `_2`
   - continue until unique.

### Example

If:

```text
chart.png
```

already exists:

```text
chart_1.png
chart_2.png
```

will be generated.

### Variables

| Variable | Purpose |
|----------|----------|
| `file_name` | Original filename |
| `stem` | Filename without extension |
| `suffix` | Extension |
| `output_path` | Final path |
| `counter` | Duplicate counter |

### Importance

⭐⭐⭐⭐⭐ Critical

Without it, generated files could overwrite older results.

# Function 4: `download_container_file(...)`

```python
def download_container_file(
    openai_client,
    annotation,
    downloaded_files
):
```

## Responsibility

Downloads files referenced by the agent.

### Workflow

### Step 1

Create cache key:

```python
cache_key = (
    annotation.container_id,
    annotation.file_id
)
```

### Step 2

Check cache

```python
if cache_key in downloaded_files:
```

Avoids duplicate downloads.

### Step 3

Download file

```python
openai_client.containers.files.content.retrieve()
```

### Step 4

Save locally

```python
save_bytes()
```

### Step 5

Store in cache

```python
downloaded_files[cache_key]
```

### Importance

⭐⭐⭐⭐⭐

Prevents repeated downloads and saves bandwidth.

### Variables

| Variable | Purpose |
|----------|----------|
| `cache_key` | Unique file identifier |
| `file_content` | Downloaded data |
| `output_path` | Saved location |
