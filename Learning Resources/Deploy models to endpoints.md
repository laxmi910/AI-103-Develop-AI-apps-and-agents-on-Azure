| Deployment Type | Explanation  | Use Case |
|----------------|--------------------------|-----------|
| Global Standard | Uses any Azure region, pay-per-use, best for general workloads with highest quota | Global chatbot or SaaS app with users from multiple countries |
| Global Provisioned | Uses any region with reserved capacity (PTUs) for consistent high performance | High-traffic enterprise app needing stable response (e.g., customer support AI) |
| Global Batch | Runs large async jobs globally at lower cost (50% discount) within 24 hours | Processing millions of documents or logs overnight |
| Data Zone Standard | Ensures data stays in EU/US zone, pay-per-use | Applications handling regulated data (e.g., EU GDPR apps) |
| Data Zone Provisioned | Reserved capacity within a data zone for predictable performance | Banking or healthcare apps needing compliance + steady performance |
| Data Zone Batch | Batch processing within a specific data zone | Bulk processing of sensitive records (e.g., medical data in EU) |
| Standard | Runs in one region, pay-per-use, good for low volume or compliance | Small apps needing data in one country (e.g., internal tools) |
| Regional Provisioned | Reserved capacity within a single region | High-usage app focused on one country (e.g., local e-commerce AI) |
| Developer | Pay-per-use, any region, only for testing/fine-tuning | Testing prompts or evaluating fine-tuned models |
